# TL;DR Today

Too Long; Didn't Read, so the owls read it for you. A wizarding-style daily newspaper, printed fresh every morning at 08:00 IST from global and Indian news feeds, with every headline rewritten in plain English (and a little Gen Z slang) by GitHub Models.

- **Global:** BBC News, The New York Times, The Guardian, Al Jazeera, NPR, BBC Business, The Verge, ScienceDaily, ESPN, BBC Sport
- **India:** The Hindu, Times of India, The Indian Express, Hindustan Times, NDTV, The Economic Times, Mint, The Hindu BusinessLine, ESPNcricinfo

**Read it:** https://10priyankasinghofficial-code.github.io/morning-roundup/

- `build.py` fetches the feeds, rewrites them, and renders `template.html` into `site/index.html`
- `.github/workflows/daily.yml` runs it daily and deploys to GitHub Pages

Headlines and photographs belong to their publishers; every story links to the original.
